WIREFRAME DETAIL PROJECT - KELOMPOK PEMERIKSAAN MRO
Rancangan untuk diskusi UX | 23 November 2026

Buka WIREFRAME-DETAIL-PROJECT.html di browser desktop/mobile.
File mandiri tidak membutuhkan instalasi atau internet.
Rancangan ini terpisah dari mockup MRO utama.

Coba alur berikut:
1. Dari timeline, buka Rencana kebutuhan impor.
2. Pilih Hydraulic pump. Bandingkan part number rencana dengan bukti contoh.
3. Isi penilaian dan catatan. Draft disimpan pada browser masing-masing.
4. Filter Belum dinilai, lalu pindah kelompok dan kembali.
5. Catat temuan dari panel penilaian; tinjau lewat tab Temuan.
6. Coba Impor Excel > Gunakan contoh berkas > Preview & validasi.
7. Terapkan dua baris valid contoh, lalu periksa data hasil impor.
8. Tutup ruang pemeriksaan untuk melihat ringkasan progres.

Di desktop, navigasi kelompok, tabel, bukti, dan penilaian berada dalam satu
ruang kerja. Pada layar kecil, tabel dan bukti dipisahkan melalui tab.

Impor menampilkan simulasi dengan data contoh. Isi file Excel yang dipilih
tidak dibaca atau diunggah. Template dan ekspor menghasilkan file XLSX.
Seluruh bukti adalah representasi; aturan penyelesaian kelompok merupakan
usulan UX yang perlu dikonfirmasi dengan client/SOP. Tidak ada autentikasi,
backend, keputusan verifikasi, atau penerbitan dokumen resmi.

Reset data contoh memulihkan contoh awal pada wireframe ini saja setelah
konfirmasi. Penyimpanan terpisah dari mockup MRO utama.

Source yang dapat diedit: wireframe/index.html, style.css, app.js.
Build ulang: python scripts/build-wireframe.py (dari folder mro-mockup).
